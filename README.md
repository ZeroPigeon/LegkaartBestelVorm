# Legkaart Bestel Vorm / Puzzle Ordering Form

## Overview

a small ordering form for puzzles of different age groups. I created this for a church project to gain experience and provide a good-looking product for customers to use instead of a google form. One main requirement was that the form should be in Afrikaans.

## Features

- Preview selected puzzle for age group
- Sends orders to appropriate staff in an easy to read format
- Calculates price for puzzles before ordering

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

Pick a puzzle for the specific age group that you want and get a preview of how the puzzle looks before you order it. Orders can be edited in the selected table, if 0 is selected the item will be removed from the order. When submitting the order, it will open you emailing software and fill out the email for you to send to the appropriate staff that will handle the next steps in the order.

- Event handling for websites
- Using JavaScript to prepare an email for the client to send to someone.
